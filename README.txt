Symulacja codziennego życia mieszkańców gospodarstwa rolnego


Opis projektu 
Projekt przedstawia symulację codziennego życia mieszkańców gospodarstwa rolnego z wykorzystaniem drzew zachowań (Behavior Trees) oraz systemu nawigacji NavMesh w silniku Unity. Celem projektu jest odwzorowanie realistycznych zachowań postaci (NPC), takich jak: wykonywanie codziennych obowiązków (np. praca w polu, opieka nad zwierzętami), przemieszczanie się po mapie z wykorzystaniem NavMesh, reagowanie na zmieniające się warunki (np. pora dnia).


Jak uruchomić projekt
1. Pobierz projekt

 Sklonuj repozytorium: git clone <link do repozytorium>
 lub pobierz projekt jako ZIP i rozpakuj go.

2. Zainstaluj Unity Hub

 Pobierz Unity Hub: https://unity.com/download

3. Zainstaluj odpowiednią wersję Unity

 Otwórz Unity Hub.
 Przejdź do zakładki Installs.
 Kliknij Install Editor.
 Zainstaluj wersję 60000.2.14f1.

4. Dodaj projekt do Unity Hub

 Przejdź do zakładki Projects.
 Kliknij Add.
 Wybierz folder projektu (z katalogami Assets, ProjectSettings, Packages).

5. Otwórz projekt
 
 Kliknij projekt na liście w Unity Hub.
 Poczekaj na załadowanie assetów i kompilację skryptów.

6. Uruchom scenę

 Otwórz folder Assets/Scenes.
 Wybierz główną scenę SampleScene.
 Kliknij Play.



Główne mechaniki
Drzewa zachowań (Behavior Trees) - sterują logiką działania NPC, umożliwiają dynamiczne podejmowanie decyzji.
Nawigacja (NavMesh) - NPC poruszają się po wcześniej wygenerowanej siatce nawigacyjnej, unikają przeszkód i wybierają optymalne ścieżki.
